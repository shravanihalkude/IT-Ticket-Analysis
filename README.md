# IT-Ticket-Analysis
This project analyzes IT support tickets to identify trends, improve operational efficiency, and monitor service performance. The dashboard provides insights into ticket volume, resolution time, issue severity, customer satisfaction, and agent performance.

# Dataset
The analysis is based on two datasets:

IT Tickets Dataset (97,498 records)
IT Agents Dataset (50 agents)

The datasets include ticket details such as request category, issue type, severity, priority, resolution time, satisfaction rate, and agent information.

# Objectives
Analyze ticket volume over time.
Identify data quality issues and missing values.
Understand the distribution of ticket categories.
Measure average resolution time and customer satisfaction.
Evaluate agent performance metrics.
Study the relationship between issue severity and resolution time.
Generate actionable insights for improving IT support operations.

# Tools Used
Microsoft Excel,
Pivot Tables,
Data Cleaning & Transformation,
Dashboard Design & Visualization.

# Key Insights
Analyzed 97,498 IT support tickets.
Login Access requests formed the largest category of tickets.
Average IT agent age was approximately 40.6 years.
Ticket severity showed very weak correlation with resolution time.
Identified data inconsistencies and quality issues for further improvement.

# Dashboard Features
Ticket Volume Analysis
Category Distribution
Resolution Time Tracking
Severity Analysis
Agent Performance Metrics
Customer Satisfaction Monitoring

# Business Impact
This dashboard helps IT support teams monitor service quality, identify bottlenecks, optimize resource allocation, and improve customer experience through data-driven decision making.
